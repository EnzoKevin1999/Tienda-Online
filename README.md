Tienda Online Fullstack — PHP, MySQL y JavaScript
🎥 Proyecto: Tienda online desarrollada 100% por mí

Descripción
Esta tienda online es un proyecto completo desarrollado con PHP, MySQL y JavaScript, sin usar frameworks, enfocándome en aplicar buenas prácticas de programación, seguridad y experiencia de usuario.

Funcionalidades principales
Registro y Login con validaciones avanzadas:

Evita correos, nombres y usuarios repetidos.

Validaciones personalizadas para nombres (sin números ni símbolos, longitud controlada).

Correos con estructura válida y limpia.

Usuarios con letras y números, y longitud corta.

Login verifica existencia del usuario y muestra mensajes claros.

Sistema de roles con permisos:

Usuario común: puede comprar, ver sus compras, sin poder modificar estados ni anular compras.

Administrador: puede agregar, editar y eliminar productos (imagen obligatoria al agregar).

Gestión de talles, colores y marcas con validaciones para evitar duplicados.

Puede anular y modificar estados sólo de sus propias compras, no de otros usuarios.

Funciones de búsqueda para facilitar la gestión de productos y ventas.

Tecnologías utilizadas
PHP (sin frameworks)

MySQL para base de datos

JavaScript para validaciones y dinamismo en frontend

HTML y CSS para estructura y estilos
